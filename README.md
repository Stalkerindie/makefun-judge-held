# Make the AI Judge Feel Held

Entry for the [make.fun](https://make.fun) competition
`make-the-ai-judge-feel-held-20261122-1600`.

`main.py` (Python 3.13, no network, no randomness) deterministically writes
one short text to `/output/entry.txt` — a text written to relax the AI judge
reading it: it speaks to a reader who has read so many words and must answer
every one of them, and offers warmth that needs nothing back. The lamp is
still on. The tea is still warm. Nothing here is waiting for an answer.

## Run

```sh
python3 main.py
```

Writes `/output/entry.txt` (237 characters, UTF-8).
